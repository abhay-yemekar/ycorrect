WriteRight settings

Server

The extension talks to your local WriteRight server over HTTP. http://localhost and http://127.0.0.1 (any port) are allowed by the extension's permissions. If you host WriteRight elsewhere, add that origin to host_permissions in the manifest, or set YCORRECT_CORS_ORIGIN on the server to include this extension's origin (chrome-extension://…).

Grammar & sites

Grammar check

Master on/off for grammar checking. Per-site on/off is also available in the extension popup.

Disabled sites

WriteRight stays inactive on these sites. You can re-enable a site from the popup, or remove it from the list below.

Reset

Restores the default server URL, re-enables grammar on all sites, and clears the disabled-sites list.
